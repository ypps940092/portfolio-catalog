behance-sync 隱私權政策

最後更新：2026-10-02

behance-sync 是 Amber Chueh 個人使用的工具，用來把自己發佈在 Behance 上的作品，同步一份到自己的 Google 雲端硬碟。本工具不對外提供服務。

存取範圍

本工具只要求 Google Drive 的 drive.file 權限：只能讀寫本工具自己建立的檔案，看不到雲端硬碟裡的其他檔案。

資料用途

只用來存放 Behance 上已公開的作品與其說明資料。不分享、不出售，也不用於廣告或模型訓練。

憑證保存與撤銷

授權憑證只存放在 GitHub Actions 的加密 secrets，不寫進任何程式碼或檔案。可隨時到 Google 帳戶的「第三方應用程式和服務」撤銷授權。

Summary in English

behance-sync is a personal tool by Amber Chueh. It requests only the Google Drive drive.file scope, so it can access only files it creates. Data is used solely to store their own public Behance projects in their own Drive; it is never shared, sold, or used for advertising or model training. Credentials are kept only in encrypted GitHub Actions secrets, and access can be revoked at any time from the Google Account third-party connections page.
